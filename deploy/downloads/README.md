Put the desktop installers for the current `desktop_version` here (the files from `servio-desktop/release/` or the GitHub Release): the site serves this folder at `/downloads`, and the Download page links to the files by electron-builder's names, e.g. `EasAlpha POS Setup 0.2.0.exe`, `EasAlpha POS-0.2.0.AppImage`, `servio-desktop_0.2.0_amd64.deb`, `EasAlpha POS-0.2.0.dmg`, `EasAlpha POS-0.2.0-arm64.dmg`. Binaries are not committed.
